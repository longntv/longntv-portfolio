# Discovery Questions

## Q1: Should only you (a single admin) be able to edit content, while all other visitors see a read-only site?
**Default if unknown:** Yes (personal portfolio; inline editing must be protected by a login/secret).

## Q2: Should the site keep the existing theme (dark/purple, particles, Bootstrap) and extend it with new sections inspired by the reference (Journey/Experience, Skills, Certifications)?
**Default if unknown:** Yes ("dùng theme của tôi" — reuse current look, borrow only the information architecture).

## Q3: Do you need each project to have its own detail page (longer write-up, images, role, results), not just a card?
**Default if unknown:** Yes ("những nội project tôi làm" suggests showing project content in depth, which the reference lacks).

## Q4: Is it acceptable to deploy on a free serverless platform (e.g. Vercel/Cloudflare) with a hosted lightweight DB (e.g. SQLite/Turso, Supabase, or a JSON doc store) instead of running your own server?
**Default if unknown:** Yes (cheapest, least maintenance for a "rất nhẹ" DB).

## Q5: Do you need the site in two languages (Vietnamese + English)?
**Default if unknown:** No (keeps editing simple; English only, can be added later).
